Hubungkan Menfess ke Instagram

Ikuti urutan ini satu kali untuk menghubungkan akun Instagram Professional, Meta Developer, dan server produksi. Nilai token tidak pernah ditulis di kode maupun halaman ini.

Mulai dari langkah 1 Buka Admin Mading
Yang disiapkanInstagram Professional + Facebook Page
Yang disimpan di serverInstagram User ID + access token
Cara uji saat iniTombol “Terbitkan IG” di Admin Mading

Setup utama

Kerjakan sesuai urutan

Gunakan akun Facebook yang memang menjadi admin aset USU Polmed. Jangan menggunakan akun pinjaman karena access token bergantung pada izin pengelolanya.

1

Ubah akun Menfess menjadi Instagram Professional

  1. Buka akun Instagram khusus Menfess.
  2. Masuk ke Settings and privacy → Account type and tools.
  3. Pilih Switch to professional account → Business.
  4. Pastikan akun bersifat publik, bukan private.
2

Hubungkan ke Facebook Page

  1. Buat Facebook Page khusus, misalnya USU Polmed Menfess.
  2. Buka Meta Business Suite.
  3. Masuk ke Settings → Business assets, lalu tambahkan Page dan akun Instagram tadi.
  4. Hubungkan keduanya dan berikan admin akses untuk membuat konten.

Backend saat ini menggunakan Instagram API melalui Facebook Login, sehingga hubungan Page dan Instagram Professional diperlukan.

3

Buat aplikasi di Meta for Developers

  1. Buka Meta for Developers → My Apps.
  2. Pilih Create App dengan tipe Business.
  3. Gunakan nama seperti USU Polmed Auto Publisher.
  4. Hubungkan aplikasi ke Business Portfolio yang memiliki Page dan Instagram Menfess.
  5. Tambahkan produk Instagram API with Facebook Login.
4

Aktifkan izin publikasi

Token yang digunakan untuk tes harus memiliki izin berikut:

instagram_basic instagram_content_publish pages_show_list pages_read_engagement

Untuk akun Instagram yang dimiliki dan dikelola sendiri, gunakan akses aplikasi bagi aset sendiri. Advanced Access diperlukan ketika aplikasi melayani aset milik pihak lain.

5

Ambil Instagram User ID dan token

  1. Buka Graph API Explorer.
  2. Pilih aplikasi yang baru dibuat dan generate User Access Token dengan empat izin di atas.
  3. Jalankan permintaan berikut:
GET /me/accounts?fields=id,name,access_token,instagram_business_account
  • Simpan nilai instagram_business_account.id sebagai META_IG_USER_ID.
  • Simpan nilai access_token sebagai META_IG_ACCESS_TOKEN.
  • Jangan memakai username Instagram atau Facebook Page ID sebagai Instagram User ID.
6

Simpan konfigurasi di Vercel

  1. Buka project jualbeliusupolmed di Vercel.
  2. Masuk ke Settings → Environment Variables.
  3. Tambahkan variabel untuk environment Production:
META_IG_USER_ID META_IG_ACCESS_TOKEN NEXT_PUBLIC_SITE_URL=https://www.jualbeliusupolmed.web.id CRON_SECRET

Setelah menyimpan environment variable, lakukan Redeploy. Nilai baru tidak diterapkan ke deployment lama.

Aturan keamanan

Jangan kirim token lewat chat, screenshot, GitHub, atau kode sumber. Jangan beri nama token dengan awalan NEXT_PUBLIC_ karena token hanya boleh dibaca server. Untuk produksi jangka panjang, ganti token tes dengan long-lived token atau System User token.

Pengujian

Pastikan posting benar-benar terbit

Gunakan satu Menfess pengujian yang tidak mengandung data pribadi atau konten sensitif.

1 · Website

Buat Menfess pengujian

Kirim satu Menfess dari website dan pastikan posting muncul normal di Mading beserta gambar Instagram 1080 × 1350.

2 · Admin

Tekan “Terbitkan IG”

Buka Admin Mading, cari posting pengujian, lalu tekan tombol sekali. Tunggu status berubah dari antre menjadi diproses dan akhirnya terbit.

3 · Instagram

Periksa hasilnya

Pastikan gambar, caption, identitas anonim, dan akun tujuan benar. Jangan menekan tombol berulang selama status masih diproses.

4 · Operasional

Perhatikan status gagal

Jika gagal, perbaiki token, izin, atau hubungan aset terlebih dahulu. Setelah penyebab selesai, baru lakukan percobaan ulang.

Status sistem saat ini

Gambar dan jalur publikasi Instagram sudah tersedia. Pemicu produksi saat ini masih tombol Terbitkan IG pada Admin Mading. Auto-post langsung saat pengguna mengirim Menfess adalah tahap aktivasi terpisah dan tidak boleh dianggap aktif sebelum diuji di akun tujuan.

Dua akun tujuan

Pisahkan Menfess dan Katalog

Jangan menukar ID maupun token kedua akun karena konten dapat terbit ke akun yang salah.

Menfess

Akun khusus cerita anonim

Menggunakan META_IG_USER_ID dan META_IG_ACCESS_TOKEN. Jalur gambar dan publikasinya sudah tersedia pada Admin Mading.

Katalog · berikutnya

Akun khusus barang dan jasa

Siapkan akun Professional, Page, ID, dan token yang berbeda. Jangan mengisi token Katalog ke variabel Menfess sebelum jalur publikasi Katalog selesai dipasang dan diuji.
