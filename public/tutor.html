USU Polmed Update

Pasang Auto-post Instagram

Panduan admin untuk menghubungkan Menfess USU Polmed ke Instagram secara aman: konten tetap diseleksi manusia, lalu diterbitkan dengan satu tombol.

Mulai Setup Buka Admin Mading

Sebelum mulai

1

Akun Professional

Ubah akun Instagram khusus Menfess menjadi akun Professional dan hubungkan ke Facebook Page yang dikelola admin.

2

Akses Meta

Buat akses publikasi lewat Meta untuk memperoleh ID akun Instagram dan access token dengan izin publikasi konten.

3

Domain publik

Pastikan domain website aktif via HTTPS. Instagram harus dapat mengambil gambar Menfess yang dibuat sistem.

Pasang konfigurasi di server

Simpan rahasia hanya di environment server

  1. Di Vercel, isi META_IG_ACCESS_TOKEN dan META_IG_USER_ID untuk akun Menfess. Jangan masukkan nilainya ke kode, GitHub, atau halaman ini.
  2. Pastikan NEXT_PUBLIC_SITE_URL mengarah ke domain produksi agar gambar posting dapat diakses Meta.
  3. Jalankan migrasi Supabase yang membuat antrean publikasi Instagram, lalu deploy versi website terbaru.

Untuk keamanan, satu akun Instagram sebaiknya memakai token dan ID akun sendiri. Jangan memakai token yang sama untuk akun Menfess dan Katalog.

Alur auto-post

1

Menfess masuk

Menfess yang melewati validasi sistem langsung masuk antrean akun Instagram Menfess.

2

Iklan menjadi aktif

Listing jual yang aktif langsung masuk antrean akun Katalog USU Polmed.

3

Sistem menerbitkan

Sistem membuat gambar, mengirimnya ke akun tujuan, dan mencatat status terbit atau gagal pada panel admin.

Untuk tiga akun Instagram

USU Polmed Update untuk konten umum yang dikurasi manual; akun Menfess untuk post Mading yang disetujui; dan Katalog USU Polmed untuk iklan jual aktif. Masing-masing perlu koneksi Meta dan riwayat publikasinya sendiri agar konten tidak tertukar.
